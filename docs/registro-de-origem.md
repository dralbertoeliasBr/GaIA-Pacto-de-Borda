# Registro de origem e alterações

Este repositório foi criado para organizar uma proposta pública de colaboração GaIA. Seu conteúdo inicial é um pacto e um índice de referências — não é um clone integral de código.

## Compromissos

- Não alterar nem substituir os repositórios de origem por meio deste repositório.
- Indicar de onde veio cada código, texto ou material incorporado futuramente.
- Preservar os avisos de autoria e as licenças originais aplicáveis.
- Registrar alterações, versões e contribuições de forma compreensível.
- Distinguir contribuições humanas do uso de ferramentas de IA quando essa informação estiver disponível.
- Não declarar participação financeira, royalty, token ou endosso sem termos explícitos e válidos.

## Antes de incorporar um projeto

1. Confirmar o repositório e a versão de origem.
2. Conferir licença, autoria, dependências e contribuições de terceiros.
3. Registrar o que foi copiado e o que foi alterado.
4. Manter a atribuição e avisos exigidos.

Até que essa revisão seja feita, os links do README são referências; os arquivos originais permanecem em seus próprios repositórios.
